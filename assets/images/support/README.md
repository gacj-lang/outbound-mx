# Imágenes de apoyo visual

Coloca aquí SVGs que quieras usar en brochures, propuestas y contenido generado.

## Cómo agregar imágenes:
1. Copia el archivo .svg a esta carpeta
2. Haz commit y push al repositorio
3. La imagen estará disponible en:
   https://gacj-lang.github.io/outbound-mx/assets/images/support/TU_ARCHIVO.svg
